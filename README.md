# shinll

## 중고차 시세 조회 앱

모델명과 연식을 입력하면 유사한 중고차 매물의 시세(평균/중간값/최저가/최고가)와
비슷한 매물 리스트를 보여주는 정적 웹앱입니다.

### 실행 방법

빌드 없이 브라우저에서 `index.html`을 바로 열면 됩니다.

```bash
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

### 동작 방식

- `assets/data.js`에 샘플 시세 데이터(현대/기아/제네시스/수입차 등 28개 모델,
  2016~2025년식, 총 500여 건)가 정적으로 들어 있습니다. 실제 매물 데이터가
  아닌 데모용 샘플입니다.
- `app.js`가 입력한 모델명을 문자열 유사도(Levenshtein 기반)로, 연식을
  차이값 기반으로 채점해 유사도 점수가 높은 순으로 매물을 정렬해 보여줍니다.
- 일치/유사 모델을 찾지 못하면 가장 가까운 모델명을 추천해줍니다.
- 샘플 데이터는 `node scripts/generate-data.js`로 재생성할 수 있습니다.

### 파일 구조

- `index.html` — 페이지 구조
- `style.css` — 스타일
- `app.js` — 검색/유사도 계산/렌더링 로직
- `assets/data.js` — 샘플 시세 데이터
- `scripts/generate-data.js` — 샘플 데이터 생성 스크립트
