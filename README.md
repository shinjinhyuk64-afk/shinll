# shinll

## 중고차 시세 조회 앱

모델명과 연식을 입력하면 유사한 중고차 매물의 시세(평균/중간값/최저가/최고가)와
비슷한 매물 리스트를 보여주는 정적 웹앱입니다.

### 실행 방법

빌드 없이 브라우저에서 `index.html`을 바로 열면 됩니다.

```bash
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

### 동작 방식

- `assets/data.js`에 샘플 시세 데이터(현대/기아/제네시스/수입차 등 28개 모델,
  2016~2025년식, 총 500여 건)가 정적으로 들어 있습니다. 실제 매물 데이터가
  아닌 데모용 샘플입니다.
- `app.js`가 입력한 모델명을 문자열 유사도(Levenshtein 기반)로, 연식을
  차이값 기반으로 채점해 유사도 점수가 높은 순으로 매물을 정렬해 보여줍니다.
- 일치/유사 모델을 찾지 못하면 가장 가까운 모델명을 추천해줍니다.
- 샘플 데이터는 `node scripts/generate-data.js`로 재생성할 수 있습니다.

### 파일 구조

- `index.html` — 페이지 구조
- `style.css` — 스타일
- `app.js` — 검색/유사도 계산/렌더링 로직
- `assets/data.js` — 샘플 시세 데이터
- `scripts/generate-data.js` — 샘플 데이터 생성 스크립트

## ⛳ 골프장 홀맵 (`golf/`)

골프장명과 코스를 입력하면 1~18번홀 위성 홀맵과 홀별 거리를 보여주는 정적 웹앱입니다.

### 실행 방법

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/golf/ 접속
```

### 기능

- **골프장 검색**: 국내 골프장을 이름으로 검색합니다 (`CC`, `컨트리클럽` 등은 생략해도 됨).
- **코스 선택**: 27/36홀 골프장은 코스별로 나눠서 보여주고, 코스 입력란(예: `동, 서`)이나
  코스 칩을 누른 순서대로 전반/후반 18홀을 구성합니다.
- **홀맵**: 위성사진 위에 티 → 그린 경로, 도그렉 지점까지 거리/남은 거리, 그린 위치를 표시합니다.
- **거리**: 홀 길이, 그린 앞/중앙/뒤까지 거리(m/yd 전환), 스코어카드(OUT/IN/합계).
- **지도 탭 측정**: 지도를 탭하면 티(또는 내 위치) → 지점 → 그린 중앙 거리를 계산합니다.
- **내 위치**: 라운드 중 GPS로 현재 위치에서 그린 앞/중앙/뒤까지 거리를 보여줍니다.
- **공유 링크**: 주소창 `#q=골프장&c=코스&id=way/123` 형태로 같은 화면을 다시 열 수 있습니다.

### 데이터와 한계

- 홀 데이터는 [OpenStreetMap](https://www.openstreetmap.org)(`golf=hole`, `golf=green` 등)을
  Overpass API로 실시간 조회하고, 위성사진은 Esri World Imagery를 사용합니다.
- 거리는 OSM에 그려진 홀 경로 기준 계산값이라 실제 스코어카드 거리와 차이가 날 수 있고,
  PAR가 등록되지 않은 홀은 거리로 추정(기울임체 표시)합니다.
- OSM에 홀이 등록되지 않은 골프장은 위성사진에서 직접 탭해 거리를 재는 모드로 동작합니다.

### 파일 구조

- `golf/index.html` — 페이지 구조
- `golf/style.css` — 스타일 (다크 모드 지원)
- `golf/geo.js` — 거리 계산, 홀 파싱, 코스 분리(27/36홀) 등 순수 로직
- `golf/app.js` — 검색, 지도(Leaflet), 화면 렌더링
